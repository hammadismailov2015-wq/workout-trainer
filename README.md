# 💪 Домашний Тренажёр

Веб-приложение для домашних тренировок без оборудования: приседания, отжимания, пресс, планка и другие упражнения. Работает офлайн, ничего устанавливать не нужно.

## Как запустить

Просто открой файл `index.html` в браузере (на телефоне или компьютере). Всё работает локально.

Для локального сервера (по желанию):

```bash
python3 -m http.server 8000
# затем открой http://localhost:8000
```

## Возможности

- **6 готовых программ** — «Всё тело», «Пресс и кор», «Ноги и ягодицы», «Верх тела», «Кардио», «Быстрая 5 мин».
- **Свой конструктор** — выбери упражнения, задай время работы/отдыха и число кругов.
- **Таймер с кругом** — обратный отсчёт, фазы «работа/отдых/подготовка», звуковые сигналы.
- **Управление** — пауза, следующее/предыдущее упражнение.
- **Статистика** — количество тренировок, минут и дней подряд (сохраняется в браузере).
- **Оценка калорий** и итоги после каждой тренировки.

## Упражнения

Приседания, отжимания, пресс, планка, выпады, бёрпи, джампинг-джек, скалолаз,
подъём ног, бег с высоким подниманием колен, супермен, стульчик у стены.
